# Activity Handlers

In BotBuilder, you create a bot by inheriting from `ActivityHandler` or `TeamsActivityHandler` and overriding methods like `OnMessageActivityAsync`, `OnMembersAddedAsync`, etc. Teams AI Library v2 takes a different approach with **attribute-based routing** (controller style) or **functional handlers** (minimal style), making your code cleaner and more testable.

## Basic Message Handling

The most common activity to handle is incoming messages from users.

### BotBuilder Approach

<Tabs>
  <TabItem value="BotBuilder" label="BotBuilder">
    ```csharp showLineNumbers
    using Microsoft.Bot.Builder;
    using Microsoft.Bot.Schema;

    public class EchoBot : ActivityHandler
    {
        protected override async Task OnMessageActivityAsync(
            ITurnContext<IMessageActivity> turnContext, 
            CancellationToken cancellationToken)
        {
            var replyText = $"Echo: {turnContext.Activity.Text}";
            await turnContext.SendActivityAsync(
                MessageFactory.Text(replyText), 
                cancellationToken);
        }

        protected override async Task OnMembersAddedAsync(
            IList<ChannelAccount> membersAdded, 
            ITurnContext<IConversationUpdateActivity> turnContext, 
            CancellationToken cancellationToken)
        {
            foreach (var member in membersAdded)
            {
                if (member.Id != turnContext.Activity.Recipient.Id)
                {
                    await turnContext.SendActivityAsync(
                        MessageFactory.Text("Welcome!"), 
                        cancellationToken);
                }
            }
        }
    }
    ```
  </TabItem>
</Tabs>

### Teams AI Library v2 Approach

<Tabs>
  <TabItem value="Controller" label="Controller Style" default>
    ```csharp showLineNumbers
    using Microsoft.Teams.Api.Activities;
    using Microsoft.Teams.Apps.Annotations;

    [TeamsController("main")]
    public class MainController
    {
        [Message]
        public async Task OnMessage(
            [Context] MessageActivity activity, 
            [Context] IContext.Client client)
        {
            var replyText = $"Echo: {activity.Text}";
            await client.Send(replyText);
        }

        [Install]
        public async Task OnInstall(
            [Context] InstallUpdateActivity activity, 
            [Context] IContext.Client client)
        {
            await client.Send("Welcome!");
        }
    }
    ```
  </TabItem>
  <TabItem value="Minimal" label="Minimal Style">
    ```csharp showLineNumbers
    using Microsoft.Teams.Apps;

    var builder = WebApplication.CreateBuilder(args);
    builder.AddTeams();

    var app = builder.Build();
    var teams = app.UseTeams();

    teams.OnMessage(async context =>
    {
        var replyText = $"Echo: {context.Activity.Text}";
        await context.Send(replyText);
    });

    teams.OnInstall(async context =>
    {
        await context.Send("Welcome!");
    });

    app.Run();
    ```
  </TabItem>
</Tabs>

## Common Activity Handler Mappings

Here's a reference table for mapping BotBuilder methods to Teams AI Library v2 attributes:

| BotBuilder Method | Teams AI v2 Attribute | Activity Type |
|------------------|----------------------|---------------|
| `OnMessageActivityAsync` | `[Message]` | Message from user |
| `OnMembersAddedAsync` | `[Install]` | Bot/app installed |
| `OnMembersRemovedAsync` | `[Uninstall]` | Bot/app uninstalled |
| `OnTeamsChannelCreatedAsync` | `[ChannelCreated]` | Channel created |
| `OnTeamsChannelDeletedAsync` | `[ChannelDeleted]` | Channel deleted |
| `OnTeamsChannelRenamedAsync` | `[ChannelRenamed]` | Channel renamed |
| `OnTeamsTeamRenamedAsync` | `[TeamRenamed]` | Team renamed |
| `OnTeamsMembersAddedAsync` | `[MembersAdded]` | Members added to team |
| `OnTeamsMembersRemovedAsync` | `[MembersRemoved]` | Members removed from team |
| `OnInvokeActivityAsync` | `[Invoke]` or specific invoke attributes | Invoke activities |

## Handling Invoke Activities

BotBuilder uses `OnInvokeActivityAsync` for all invoke activities, requiring you to check the activity name. Teams AI Library v2 provides specific attributes for common invoke patterns:

<Tabs groupId="migration-comparison">
  <TabItem value="BotBuilder" label="BotBuilder">
    ```csharp showLineNumbers
    protected override async Task<InvokeResponse> OnInvokeActivityAsync(
        ITurnContext<IInvokeActivity> turnContext,
        CancellationToken cancellationToken)
    {
        if (turnContext.Activity.Name == "composeExtension/query")
        {
            // Handle message extension query
            return CreateInvokeResponse(/* ... */);
        }
        else if (turnContext.Activity.Name == "adaptiveCard/action")
        {
            // Handle adaptive card action
            return CreateInvokeResponse(/* ... */);
        }
        
        return CreateInvokeResponse();
    }
    ```
  </TabItem>
  <TabItem value="Teams AI" label="Teams AI v2" default>
    ```csharp showLineNumbers
    [MessageExtension.Query]
    public async Task<MessagingExtensionResult> OnQuery(
        [Context] MessageExtensionQueryActivity activity,
        [Context] IContext.Client client)
    {
        // Handle message extension query
        return new MessagingExtensionResult(/* ... */);
    }

    [AdaptiveCard.Action]
    public async Task OnAdaptiveCardAction(
        [Context] AdaptiveCardInvokeActivity activity,
        [Context] IContext.Client client)
    {
        // Handle adaptive card action
    }
    ```

## Dependency Injection

One of the biggest advantages of Teams AI Library v2 is native dependency injection support:

<Tabs groupId="migration-comparison">
  <TabItem value="BotBuilder" label="BotBuilder">
    ```csharp showLineNumbers
    public class MyBot : ActivityHandler
    {
        private readonly IConfiguration _configuration;
        private readonly ILogger<MyBot> _logger;

        public MyBot(IConfiguration configuration, ILogger<MyBot> logger)
        {
            _configuration = configuration;
            _logger = logger;
        }

        protected override async Task OnMessageActivityAsync(
            ITurnContext<IMessageActivity> turnContext,
            CancellationToken cancellationToken)
        {
            _logger.LogInformation("Received message");
            // ...
        }
    }

    // Startup.cs
    services.AddTransient<IBot, MyBot>();
    ```
  </TabItem>
  <TabItem value="Teams AI" label="Teams AI v2" default>
    ```csharp showLineNumbers
    [TeamsController("main")]
    public class MainController
    {
        private readonly IConfiguration _configuration;
        private readonly ILogger<MainController> _logger;

        // Constructor injection works naturally
        public MainController(
            IConfiguration configuration, 
            ILogger<MainController> logger)
        {
            _configuration = configuration;
            _logger = logger;
        }

        [Message]
        public async Task OnMessage(
            [Context] MessageActivity activity,
            [Context] IContext.Client client)
        {
            _logger.LogInformation("Received message");
            // ...
        }
    }

    // Program.cs
    builder.Services.AddTransient<MainController>();
    ```
  </TabItem>
</Tabs>

## Pattern Matching and Routing

Teams AI Library v2 also supports pattern matching for messages:

```csharp
[TeamsController("main")]
public class MainController
{
    // Match specific text
    [Message("/help")]
    public async Task OnHelpCommand(
        [Context] MessageActivity activity,
        [Context] IContext.Client client)
    {
        await client.Send("Help information...");
    }

    // Regular expression matching
    [Message(@"/remind (?<when>\w+)")]
    public async Task OnRemindCommand(
        [Context] MessageActivity activity,
        [Context] IContext.Client client)
    {
        var when = activity.Text; // Extract "when" from regex
        await client.Send($"I'll remind you {when}");
    }

    // Catch-all for other messages
    [Message]
    public async Task OnMessage(
        [Context] MessageActivity activity,
        [Context] IContext.Client client)
    {
        await client.Send($"You said: {activity.Text}");
    }
}
```

## Testing

Teams AI Library v2 makes testing much easier with dependency injection:

```csharp
public class MainControllerTests
{
    [Fact]
    public async Task OnMessage_EchoesUserInput()
    {
        // Arrange
        var mockClient = new Mock<IContext.Client>();
        var controller = new MainController();
        var activity = new MessageActivity { Text = "Hello" };

        // Act
        await controller.OnMessage(activity, mockClient.Object);

        // Assert
        mockClient.Verify(
            c => c.Send("You said: Hello"), 
            Times.Once);
    }
}
```
