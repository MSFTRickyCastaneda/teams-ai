# Sending Activities

One of the most common operations in a bot is sending messages back to users. BotBuilder uses `MessageFactory` and `SendActivityAsync`, while Teams AI Library v2 simplifies this with a unified `Send` method that handles various message types more elegantly.

### Adaptive Card with Actions

<Tabs groupId="migration-comparison">

  <TabItem value="Teams AI" label="Teams AI v2" default>

    })
    .AddAction(new SubmitAction("Option B")

## Streaming Messages

Teams AI Library v2 introduces streaming support for long-form responses:

```csharp
[Message]
public void OnMessage(
    [Context] MessageActivity activity,
    [Context] IStreamer stream)
{
    stream.Emit("Processing your request");
    stream.Emit(".");
    stream.Emit(".");
    stream.Emit(".");
    stream.Emit(" Done!");
    // Result: "Processing your request... Done!"
}
```

:::note
Streaming is currently only supported in 1:1 conversations, not group chats or channels.
:::
