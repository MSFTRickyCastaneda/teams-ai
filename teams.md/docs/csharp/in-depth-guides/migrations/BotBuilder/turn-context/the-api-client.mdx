# The API Client

BotBuilder provides a static `TeamsInfo` class for making API calls to Microsoft Teams services. Teams AI Library v2 takes a more modern approach by injecting an `IContext.Api` client into your handlers, providing a fluent, discoverable API surface.

## Overview

The key differences:

- **BotBuilder**: Static methods requiring `ITurnContext` parameter
- **Teams AI v2**: Injected API client with fluent interface

## Complete API Comparison Table

| BotBuilder Method | Teams AI v2 API | Description |
|------------------|-----------------|-------------|
| `TeamsInfo.GetMembersAsync()` | `api.Conversations.Members(id).Get()` | Get conversation members |
| `TeamsInfo.GetMemberAsync()` | `api.Conversations.Members(id).Member(userId).Get()` | Get specific member |
| `TeamsInfo.GetTeamDetailsAsync()` | `api.Teams(teamId).Get()` | Get team information |
| `TeamsInfo.GetTeamChannelsAsync()` | `api.Teams(teamId).Channels().Get()` | Get team channels |
| `TeamsInfo.GetMeetingInfoAsync()` | `api.Meetings(meetingId).Get()` | Get meeting details |
| `TeamsInfo.GetPagedMembersAsync()` | `api.Conversations.Members(id).Get(pageSize, continuationToken)` | Get paginated members |
| `turnContext.SendActivityAsync()` | `api.Conversations.Activities(id).Post()` | Send activity to conversation |
| `turnContext.UpdateActivityAsync()` | `api.Conversations.Activities(id, activityId).Put()` | Update existing activity |
| `turnContext.DeleteActivityAsync()` | `api.Conversations.Activities(id, activityId).Delete()` | Delete activity |

## Fluent API Pattern

Teams AI v2's API client uses a fluent pattern that mirrors the REST API structure:

```csharp
// Conversations
await api.Conversations.Get();
await api.Conversations.Create(parameters);
await api.Conversations.Members(conversationId).Get();
await api.Conversations.Activities(conversationId).Post(activity);
await api.Conversations.Activities(conversationId, activityId).Put(activity);
await api.Conversations.Activities(conversationId, activityId).Delete();

// Teams
await api.Teams(teamId).Get();
await api.Teams(teamId).Channels().Get();
await api.Teams(teamId).Channels(channelId).Get();
await api.Teams(teamId).Members().Get();

// Meetings
await api.Meetings(meetingId).Get();
await api.Meetings(meetingId).Participants().Get();
```

## Dependency Injection

The API client is automatically available through dependency injection:

```csharp showLineNumbers
[TeamsController("main")]
public class MainController
{
    private readonly ILogger<MainController> _logger;

    public MainController(ILogger<MainController> logger)
    {
        _logger = logger;
    }

    [Message]
    public async Task OnMessage(
        [Context] MessageActivity activity,
        [Context] IContext.Client client,
        [Context] IContext.Api api)
    {
        try
        {
            var members = await api.Conversations
                .Members(activity.Conversation.Id)
                .Get();

            _logger.LogInformation(
                "Retrieved {Count} members", 
                members.Count);

            await client.Send($"Found {members.Count} members");
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Error getting members");
            await client.Send("An error occurred");
        }
    }
}
```

## Testing

The API client interface makes testing much easier:

```csharp showLineNumbers
public class MainControllerTests
{
    [Fact]
    public async Task OnMessage_RetrievesMembersSuccessfully()
    {
        // Arrange
        var mockApi = new Mock<IContext.Api>();
        var mockMembers = new Mock<IConversationMembersApi>();
        
        mockApi.Setup(a => a.Conversations.Members(It.IsAny<string>()))
            .Returns(mockMembers.Object);
        
        mockMembers.Setup(m => m.Get())
            .ReturnsAsync(new List<ChannelAccount>
            {
                new ChannelAccount { Name = "User 1" },
                new ChannelAccount { Name = "User 2" }
            });

        var mockClient = new Mock<IContext.Client>();
        var controller = new MainController();
        var activity = new MessageActivity 
        { 
            Conversation = new ConversationAccount { Id = "conv-123" } 
        };

        // Act
        await controller.OnMessage(activity, mockClient.Object, mockApi.Object);

        // Assert
        mockClient.Verify(
            c => c.Send("Found 2 members"), 
            Times.Once);
    }
}
```

## Key Benefits

1. **Discoverable API**: IntelliSense guides you through available operations
2. **Type Safety**: Strongly-typed requests and responses
3. **Fluent Interface**: Readable, chainable API calls
4. **No Static Methods**: Better testability and dependency injection
5. **Consistent Patterns**: Same patterns across all API operations
6. **Less Boilerplate**: No need to pass context everywhere
